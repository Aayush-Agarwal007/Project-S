# 📊 CryptoDash - Real-Time Cryptocurrency Market Tracker

A simple yet powerful web application to track real-time cryptocurrency prices, market trends, and signals.  
Built with **FastAPI**, **TailwindCSS**, and external APIs for fetching live crypto data.

---

## 🚀 Features
- 🔴 **Live Price Tracking** – Get real-time updates on major cryptocurrencies.  
- 📈 **Market Trends & Signals** – Visualize buy/sell signals generated from indicators.  
- 🌐 **Responsive UI** – Built with TailwindCSS for a clean, modern design.  
- 🔔 **Alerts System** – Notifies when important market events occur.  
- ⚡ **Fast & Lightweight** – Powered by FastAPI and WebSockets.  

---

## 🛠️ Tech Stack
- **Backend**: [FastAPI](https://fastapi.tiangolo.com/)  
- **Frontend**: HTML, TailwindCSS  
- **WebSockets**: Real-time updates  
- **Data**: Crypto API integration (e.g., CoinGecko, Binance API)  
- **Others**: Pandas, httpx, dotenv
